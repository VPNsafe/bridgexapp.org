BRIDGEX 更新记录

持续改进，操控更顺手。

在这里查看每次改进，以及各版本的可用状态。

2026年10月19日已准备构建

Windows 0.1.3

Windows 安装与更新

  • 已准备仅为当前用户安装的 Windows 安装程序，提供五种语言的安装界面。
  • 更新保留已保存的配对和偏好设置，卸载时可选择单独清除。
  • 已在隔离的 Windows 测试中检查安装、更新、中断恢复和卸载。接下来进行签名和实际安装验证；暂未提供 Windows 公开下载。
2026年10月19日已准备构建

Windows 0.1.2

文字大小跟随 Windows 设置

  • 新增对 Windows 文字大小设置的支持。大字号下，开发版本会切换为可滚动的单列布局。
  • 已在五种语言下检查 100%、150% 和 225% 文字大小的界面。
  • 修改自动启动设置前会核对应用的完整路径，保留属于其他副本的记录。
  • Windows 版本仍在开发中。设备、安装程序和发布验证仍在进行，暂未提供公开下载。
2026年10月19日已准备构建

Apple 1.0.1 / Android 0.1.8

手机和平板上的 Windows 控制

  • 开发版本新增按电脑平台显示的快捷键：Windows 使用 Ctrl，并提供 Alt+Tab、任务视图和显示桌面。Mac 保留 Command 快捷键。
  • 新增五种语言的 Windows 连接和手势说明，并保留输入预览和紧凑的键盘控制栏。
  • 这些改动尚处于开发版本，未通过应用商店发布。Windows 设备验收和安装程序开发仍在进行中。
2026年10月19日已准备构建

Windows 0.1.1

Windows 配套应用支持五种语言

  • Windows 开发版本新增英语、俄语、简体中文、西班牙语和印地语，并提供语言选择和登录 Windows 时自动启动的可选设置。
  • 改进了窄窗口和大字号下的界面布局。
  • 开发版本已实现加密蓝牙。手机蓝牙测试、安装程序和发布验证仍在进行中，暂未提供公开的 Windows 下载。
2026年10月18日已准备构建

Windows 0.1.0 prototype

Windows 控制迈出第一步

  • 首个原生 Windows 11 配套应用已完成，提供加密的本地配对、系统托盘菜单和设备访问管理。
  • 实体 iPhone 和三星手机已通过 Windows Wi-Fi 测试：发现设备、光标、输入预览、点击、按住按钮拖动、调整窗口大小、离开应用时安全松开按钮，以及手机应用冷启动后的重新连接。三星使用 Google Play 版本。多语言输入已另行通过原生 Apple 客户端和采用 Android 库的客户端测试；Windows 蓝牙和更广泛的发布测试仍待完成。
  • 开发原型已完成数字签名并通过 Windows 启动检查。公开提供 Windows 下载前，还需完成安装程序、蓝牙功能和发布测试。
2026年10月18日Google 审核中

Android 0.1.7 (8)

为平板打造的遥控界面

  • 宽窗口中，触控板与可滚动的控制面板并排显示。面板可移到左侧，窄窗口保留熟悉的紧凑布局。
  • 键盘上方保留输入预览。旋转屏幕会安全松开鼠标按钮。已在三星平板上测试 Wi-Fi、蓝牙以及断网后的重新启动。
  • 已可用于内部测试。封闭测试更新及五种语言的手机和平板商店资料已提交 Google 审核，覆盖所有已选择地区。
2026年10月18日已上传至 Apple

iPhone / iPad 1.0.1 (15)

Apple 客户端加入 iPad 支持

  • 通用 iPhone/iPad 构建支持横竖屏、左侧面板和浮动键盘，不会保留多余的底部空白。
  • 已在 iPad mini 和 13 英寸 iPad Pro 模拟器上测试，并完成 iPhone 回归检查。构建已上传至 App Store Connect，此更新尚未在 App Store 公开发布。
2026年10月18日封闭测试

Android 0.1.6 (7)

扩大 Android 封闭测试

  • 封闭测试已配置所有 Google Play 提供的地区及现有测试群组。英语、俄语、简体中文、西班牙语和印地语商店资料已更新发布。
  • Android 仍处于测试阶段。需加入符合条件的测试群组才能访问，正式公开发布尚待完成。
2026年10月16日早期测试版本

Android 0.1.6 (7)

两种手机上的熟悉布局

  • 支持系统明暗主题、紧凑键盘工具栏，并分别处理按住左键与拖动锁定。
2026年10月16日早期测试版本
