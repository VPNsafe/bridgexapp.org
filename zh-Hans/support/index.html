帮助您顺利连接

BridgeX 支持

有问题或遇到故障？请发邮件至 support@techdatacloud.org.

首次连接：手机或平板 → PC/Mac

在手机或平板上安装 BridgeX，并在电脑上安装对应的配套应用。安装顺序不限，然后打开两个应用。Mac 支持家庭网络或直连蓝牙；Windows 测试版使用 Wi-Fi。在电脑上生成二维码，用手机或平板的 BridgeX 扫描。二维码仅可使用一次，有效期为两分钟。

找不到电脑

请保持电脑开机、已登录且 BridgeX 正在运行。Wi-Fi 模式需要同一家庭网络；电脑也可以通过网线连接路由器。访客网络隔离或阻止局域网流量的 VPN 可能影响发现。连接 Mac 时也可选择蓝牙。公开 Windows 测试版的蓝牙功能尚未确认。

已连接但光标不动

在 Mac 的“系统设置 → 隐私与安全性 → 辅助功能”中允许 BridgeX。若列表中没有，请从“应用程序”添加。Windows 上请登录后打开普通应用。测试版不支持登录界面、UAC 提示或以管理员身份运行的应用。

移动窗口或调整大小

将光标放在窗口标题栏或边角。点按“按住左键”，在触控板上移动，再点按“释放”。也可以用一根手指按住“左键”，另一根手指移动。无需压力感应硬件。

滚动方向相反

在手机或平板的 BridgeX 设置中更改“反转滚动”。此选项也影响惯性滚动，并会保存到下次启动。

删除已保存的电脑或撤销手机访问

较新的移动构建提供“电脑”列表：为相应条目选择“忘记电脑”。这只会删除移动设备上的配对。要撤销手机访问，还需在电脑 BridgeX 的受信任设备列表中移除该手机。其他已保存的电脑会保留。

支持邮件应包含什么

请提供手机或平板及电脑型号、两端的系统和 BridgeX 版本、连接方式与复现步骤。错误截图不得包含私人数据。请勿发送配对码或配对二维码、密钥、密码及私人输入内容。

Windows 测试版：连接与限制

运行已签名的安装程序，从“开始”打开 BridgeX。使用同一家庭网络，并在手机上选择 Wi-Fi。出现提示时允许 BridgeX 访问局域网。保持电脑开机并登录。蓝牙尚未确认；不支持登录界面、UAC 和管理员应用。输入可能延迟或出现错误字符，尤其是长文本。请检查结果并反馈问题。

相机被拒绝或二维码已过期

无法使用相机时，可在移动端配对界面手动输入连接码。从电脑 BridgeX 复制当前有效的连接码，并私密地传到手机。二维码过期或已使用时，请在电脑上生成新的二维码。请勿将连接码放入截图或支持消息。

手机权限

iPhone/iPad 上可在“设置 → 隐私与安全性 → 本地网络”中检查 BridgeX 的 Wi-Fi 权限，在“蓝牙”中检查蓝牙权限。Android 上打开“设置 → 应用 → BridgeX → 权限”，检查用于蓝牙的“附近的设备”和扫码所需的“相机”。名称可能因设备而异。手动输入连接码不需要相机。

三指拖移与系统手势

启用三指拖移后，三根手指可移动窗口或调整大小，系统滑动手势改用四根手指。关闭后，三指滑动控制窗口和桌面。具体操作取决于 Mac 或 Windows。捏合缩放会发送快捷键，因此前台应用必须支持相应快捷键。

输入预览与 TV 控制

预览行显示手机上输入的文字，不会读取电脑输入框内容。隐藏或清空预览不会删除已发送文字；关闭键盘会清空本地草稿。使用 TV 快进、快退或全屏前，请选中视频并离开文本框。HDMI 音量可能需要电视遥控器。
