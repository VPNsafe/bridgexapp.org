BridgeX 隐私政策
更新日期：2026年11月6日

开发者：Viacheslav Kuzmin。
隐私问题或删除已发送给支持团队的信息，请联系 support@techdatacloud.org。

BridgeX 可将 iPhone、iPad、Android 手机或平板电脑用作远程鼠标和键盘。电脑端包括 Mac 配套程序和 Windows Wi-Fi 测试版。兼容性取决于应用版本，最新要求和限制见 https://bridgexapp.org/download/。远程控制无需 BridgeX 账户或开发者服务器。应用不含广告、跟踪或分析 SDK。开发者不会自动收到控制命令、输入文字、设备名称、配对密钥或会话历史。

本地连接

控制命令经过加密，在移动设备与已配对电脑之间通过支持的本地网络或蓝牙直接传输。当前公开 Windows 测试版不支持蓝牙。本地或附近设备发现可能公布电脑名称及服务可用性。控制电脑需要先配对。输入到其他应用的信息随后由该应用按其政策处理。

配对与存储

配对记录包括随机设备标识符、名称、凭据和受信任设备信息。Apple 应用在钥匙串中保护配对秘密，偏好设置保存在本地 UserDefaults。Android 在应用私有存储中保存设置，并使用 Android Keystore 密钥加密配对秘密；这些记录的备份和迁移已禁用。Windows 使用 DPAPI 保护身份和配对秘密，并在本地保存设置。不使用广告标识符。

输入文字与预览

BridgeX 不会将输入会话保存到自己的文件或发送给开发者。启用预览时，临时保存在内存中的会话上下文可在退格后补全可见末尾。Apple 设备最多预览最近512个字符，Android 最多预览最近512个 Unicode 码点。关闭键盘、断开连接、失去控制权限或切换到后台会清除本地输入上下文。清空或隐藏预览会清除预览历史。BridgeX 不读取电脑现有输入框的内容，也不录制电脑屏幕。

剪贴板与粘贴

在支持该功能的版本中，明确选择“粘贴”可读取移动设备剪贴板中的文字，并作为输入发送到已配对电脑。电脑的复制/粘贴快捷键操作电脑剪贴板。BridgeX 不监控或自动同步剪贴板。操作系统和所选键盘可能按各自政策管理自己的剪贴板历史。

权限

相机权限可选，仅用于本地扫描配对二维码；画面不保存或上传。也可手动输入配对码。蓝牙、“附近的设备”和本地网络权限用于发现与连接，不用于跟踪位置。Mac 辅助功能权限用于远程鼠标和键盘输入。Android 不使用无障碍服务。你可在系统设置中撤销权限。

删除与撤销

在移动应用的电脑列表中选择忘记设备以删除配对，并在电脑上撤销移动设备访问权以移除信任记录和关闭连接。两侧都操作才能删除双方记录。Apple 钥匙串记录可能在卸载后保留。卸载 Android 应用会删除本地应用数据，但不会撤销电脑上的信任。Windows 卸载程序允许选择是否保留配对数据。

支持与外部页面

BridgeX 不自动上传诊断信息。你自愿发送给支持团队的信息用于回复；可通过 support@techdatacloud.org 请求删除。请勿发送配对码、密钥或密码。网站或支持链接由所选浏览器或邮件应用打开。网站及托管服务商可能收到正常的 HTTP 请求元数据；BridgeX 不向其发送远程控制会话内容。

儿童与家庭

BridgeX 面向6岁及以上的电脑用户和家庭。应用不询问儿童姓名、年龄、邮箱、位置或广告标识符。没有广告、购买、公开个人资料、聊天或内容信息流。家长或监护人应监督配对及电脑上打开的内容，并可请求删除支持通信。

键盘、商店与系统服务

所选键盘按自己的政策处理输入。BridgeX 请求 Android 键盘不要使用该字段进行个性化学习，但无法保证其他键盘的行为。Apple、Google Play 和系统服务可能按各自政策处理商店、安装、许可和诊断信息，并向开发者提供汇总技术报告或你主动发送的反馈。BridgeX 不向其发送输入文字、配对密钥或远程控制会话。
