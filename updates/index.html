THE BRIDGEX CHANGELOG

Small updates. Better control.

Every improvement, in one place. See what changed and where each version is available.

18 Oct 2026Google review

Android 0.1.7 (8)

A remote made for tablets

  • Wide windows put the trackpad beside a scrollable command panel. Move the panel to the left, or use the familiar compact layout in a narrow window.
  • Typing preview stays visible with the keyboard. Rotation safely releases a held mouse button. Tested on a Samsung tablet over Wi-Fi and Bluetooth, including an offline restart.
  • Available in internal testing. The closed-test update and refreshed phone/tablet listings in five languages have been submitted to Google review for all selected regions.
18 Oct 2026Uploaded to Apple

iPhone / iPad 1.0.1 (15)

iPad joins the Apple client

  • A universal iPhone and iPad build adds portrait and landscape layouts, a left-side panel option and support for a floating keyboard without unused dock space.
  • Checked on iPad mini and 13-inch iPad Pro simulators, with iPhone regression checks. Uploaded to App Store Connect; this update is not yet a public App Store release.
18 Oct 2026Closed testing

Android 0.1.6 (7)

Closed Android testing expands

  • Closed testing is configured for every region offered in Google Play and the existing tester groups. Updated English, Russian, Simplified Chinese, Spanish and Hindi listings are published.
  • Android remains in testing. Access depends on joining an eligible tester group; a public production release is still ahead.
16 Oct 2026Earlier test build

Android 0.1.6 (7)

One familiar layout across phones

  • Android now follows the iPhone control order: a compact header, large trackpad with mouse buttons, a mode switch and grouped commands.
  • System light and dark themes, a compact keyboard toolbar and separate tracking for physical left press and drag lock.
16 Oct 2026Earlier test build

Android 0.1.5 (6) · iPhone 1.0.1 (14)

TV mode and a recoverable typing preview

  • The media mode is now called TV in all five languages, with volume, playback, seeking and full-screen controls.
  • On iPhone, the typing-preview row remains accessible when hidden. A Show button brings the preview back without restoring previously hidden text.
16 Oct 2026Earlier test build

Android 0.1.4 (5)

A cleaner start on Android

  • The two-button mouse icon and launch screen were refined to remove the unwanted white circle.
  • Connection guidance now covers iPhone and Android for PC/Mac, with current Mac support and Windows development clearly stated. Bluetooth selection and first-pairing permissions were improved.
16 Oct 2026Published

Mac 1.0.1 (13)

The Mac companion for newer clients

  • A signed, notarized universal Mac download supports the newer iPhone test builds and Android clients.
  • Available for macOS 14 and later on Apple silicon and Intel. The original Mac 1.0.0 companion remains available for the first iPhone submission.
16 Oct 2026Earlier test build

Android 0.1.3 (4)

Android arrives in Google Play testing

  • The first internal Google Play release introduced store installation and five-language listings.
  • Real phone checks covered text entry, moving and resizing a Mac window over Wi-Fi and Bluetooth, and Bluetooth after an offline restart.
16 Oct 2026Earlier test build

Android 0.1.2 (3) · Mac 1.0.1 (12)

Smoother Bluetooth and shared connections

  • Reduced severe Android cursor stutter over Bluetooth. Fixed the false busy-Mac message when switching between iPhone and Android.
  • Both clients can stay connected; real input transfers control and safely releases the previous mouse state.

More reliable Android typing

  • Added on-device editor checks for long text, composition and typing-preview privacy.

iPhone / Mac 1.0.1 (10)

Per-device secure pairing

  • Introduced a separate encrypted transport key for each paired device and refined connection ownership.
  • Upgrading from the original protocol requires a fresh pairing code. Pointer, gesture and keyboard commands continue over local Wi-Fi or Bluetooth.
