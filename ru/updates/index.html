Windows 0.1.1

Windows-компаньон на пяти языках

  • В разрабатываемую Windows-версию добавлены английский, русский, упрощённый китайский, испанский и хинди, выбор языка и настройка автозапуска при входе в Windows.
  • Улучшена компоновка для узкого окна и увеличенного текста.
  • В сборке для разработки реализован защищённый Bluetooth. Проверки Bluetooth на телефонах, установщик и подготовка выпуска ещё продолжаются; публичной загрузки Windows пока нет.

Windows 0.1.0 prototype

Первый прототип управления Windows

  • Создан нативный компаньон Windows 11 с защищённым сопряжением в локальной сети, системным треем и управлением доступом устройств.
  • Реальные iPhone и Samsung прошли проверки Windows по Wi-Fi: обнаружение, курсор, строка ввода, клики, перетаскивание с удержанием, изменение размера окна, безопасное отпускание при выходе из приложения и восстановление связи после холодного запуска приложения на телефоне. Samsung проверен со сборкой Google Play. Многоязычный текст отдельно проверен нативным Apple-клиентом и клиентом с Android-библиотеками; Bluetooth на Windows и расширенная приёмка ещё впереди.
  • Прототип подписан цифровой подписью и прошёл проверку запуска на Windows. До публичной загрузки остаются установщик, Bluetooth и приёмочные испытания.

Android 0.1.7 (8)

Пульт для большого экрана планшета

  • В широком окне тачпад и прокручиваемая панель команд расположены рядом. Панель можно перенести налево; в узком окне сохраняется привычная компоновка.
  • Строка ввода видна над клавиатурой. Поворот безопасно отпускает зажатую мышь. Проверено на Samsung по Wi-Fi и Bluetooth, включая повторный запуск без интернета.
  • Доступно во внутреннем тесте. Обновление закрытого теста и новые телефонные и планшетные карточки пяти языков отправлены на проверку Google для всех выбранных регионов.
