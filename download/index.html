MACOS · AVAILABLE

BridgeX for Mac

Control your Mac from iPhone, iPad or Android over home Wi-Fi or direct Bluetooth. Signed and notarized by Apple.

Download for Mac · 1.0.1 (28) ↓

Free · macOS 14+ · Apple silicon

Release notes and checksums ↗

INSTALL AND CONNECT

  1. Install on the Mac

    Unzip the download and drag BridgeX into Applications, then open it.

  2. Allow control

    Grant BridgeX Accessibility permission in System Settings → Privacy & Security. Allow Bluetooth if you use it.

  3. Connect your phone

    Open BridgeX on both devices. Use the same home Wi-Fi, or Bluetooth on Mac. Generate a QR code on the computer and scan it in the phone app.

Your Mac must be on and signed in. The remote-control connection does not require internet access.

WINDOWS · PUBLIC BETA

BridgeX for Windows

Turn your iPhone or Android into a mouse and keyboard for a Windows PC on the same Wi-Fi network. This early beta uses a signed installer.

Download for Windows · 0.1.9 beta ↓

Free · Windows 11 · x64 · Wi-Fi

Release notes and checksums ↗

INSTALL AND CONNECT

  1. Install on the PC

    Run the installer and open BridgeX from the Start menu.

  2. Join the same network

    Connect the phone and PC to the same home network. Allow BridgeX local-network access when prompted; choose Wi-Fi in the phone app.

  3. Scan and control

    Generate a QR code in BridgeX on the PC and scan it using BridgeX on your phone. Keep the PC on and signed in.

Requires Android or iPhone/iPad 1.0.1 from the App Store or TestFlight. Beta limits: Bluetooth is not confirmed. Login screens, UAC and elevated apps are not supported. Typing can lag or occasionally produce incorrect characters on some systems, especially with long text. Check your input and send feedback to support.
